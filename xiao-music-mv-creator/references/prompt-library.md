# 晓·音乐 MV 核心提示词

按任务复制对应文本块。把方括号里的项目输入换成定稿或本轮实际素材。写给生成工具的最终提示词要展开当前镜头的约束，项目里其他提示词可以继续保留为独立文件。

## 01 歌曲主题与歌词

```text
根据我的口述或草稿，把这首歌的表达整理成一句核心主题、一条情绪变化和三个可写进歌词的具体意象。依据明确的要求继续写词或微调。如果我只要求策划，先交歌曲简报。

输入是【灵感或歌词】、【必须保留的表达】、【希望听众感受到什么】、【可选的音乐方向】。主歌用场景和动作推进，副歌给一句唱得出来、听完能记住的钩子，桥段推进情绪或认知。句子留出换气和停顿。改词优先修改反馈指出的句段，保留我选定的标题、钩子和叙事角度。交付标题、分段歌词和这次主要改动。
```

## 02 曲风与出歌提示词

```text
根据【歌名和主题】、【歌词版本】、【希望听到的变化】和【目标生成工具】，给出适合这首歌的编曲方案，说明人声和配器怎样服务每段情绪。

交付能独立复制的风格提示词，写清主曲风、速度或律动、人声音色与唱法、主乐器和节奏组、空间与环境音、主歌和副歌的动态区别、桥段与结尾，以及需要避开的听感。BPM 和调性用已确认值或标为建议。有不同听感方向时分开写各版本，用同一版歌词供试听比较。目标工具有独立歌词框与排除项时，把各字段分别交付。
```

**完整示例 ·《雨停以后》**

```text
氛围民谣流行，Cinematic Ambient Folk Pop。写深夜下班后发现雨已经停了的松弛感。用疏落的钢琴开场，保留街边细微滴水声。主歌使用近距离女声与断续的木吉他，把换气留出来。副歌加入温暖贝斯和刷奏鼓，远处的和声稍微打开空间。尾奏逐层撤掉乐器，留下一小段路灯下的雨滴声。避免大鼓填充、强烈高音和突然拔高的励志情绪。
```

这是虚构项目的文本示例，实际出歌时用自己的歌词与制作方向替换。

## 03 音乐 MV 主分镜与镜头表

```text
根据【歌曲或有时间码的曲段】、【歌词】、【目标画幅和片长】、【人物与场景基准】设计音乐 MV。先写一句视觉主线，再给主分镜表。每段标明起止时间、曲段或拍点、叙事任务、核心画面、情绪和接下一段的方式。没有可核的音轨时间时，将拟定切点标为暂定。

把需要多动作或多机位的段落拆成能单独生成的镜头。每镜给编号、实际用时、景别、构图、动作、光线、运镜、素材身份和通过标准。检查镜头用时能覆盖目标段落，给需要留到后面才出现的视觉变化标出首次出现位置。
```

## 04 单镜静帧

```text
为【镜号】制作一张【画幅】的静帧，作为【执行包里的镜头任务】的首帧。用【角色定稿图与脸、发型、服装、配饰】锁定人物，用【场景定稿图、空间锚点、光线、材质】锁定空间。补充【景别与机位】、【人物在画面中的位置与此刻姿态】、【前景、中景、背景】和【此刻特效的强度与位置】。只表现该镜同一时刻的构图。保留【确切不能变化的细节】，禁止【该镜需要防止的变形、跑偏、遮挡或无关元素】。按要求生成单张独立画面。
```

## 05 图生视频

```text
以已通过的【首帧文件或镜号】为首帧，制作【时长与画幅】的视频。主体是【角色完整辨识特征、服装与配饰】，背景是【场景、位置关系、关键锚点和光色】。从【首帧姿态】开始，主体在镜内完成【一个主要动作及幅度】，镜头做【一个主要运镜及速度】，环境只让【指定元素】按【方向与速度】运动。停在【收尾构图、人物状态与运动方向】，用于接【下镜】。保持【具体锁定项】，禁止【该镜特有的变形、换装、跳场和遮挡】。
```

**完整示例 ·《雨停以后》04B 静帧**

```text
16:9，写实电影风，侧面中景。一位短黑卷发的成年女性，戴圆形银耳钉，穿墨绿防雨外套、深灰长裤和棕色短靴。她站在夜晚公交站棚下，单手握一把收拢的透明雨伞，微微抬眼。左边是站棚的蓝色长凳，右边是暖黄路灯，湿地倒映灯光，空气里只剩零星水滴。用站棚边框做近景，人物侧脸和雨伞清楚，湿街延伸到远处。保留服装、发型、耳钉和雨伞的样式。避免变成白天、雨伞张开、挡住脸、增加人物和可读文字。
```

**完整示例 ·《雨停以后》04B 图生视频**

```text
使用通过的 04B 静帧作首帧。16:9，生成约 5 秒供试剪。成年女性短黑卷发，圆形银耳钉，墨绿防雨外套、深灰长裤、棕色短靴，站在夜晚公交站棚下，手握收拢的透明雨伞。左侧固定蓝长凳，右侧固定暖黄路灯，地面保持潮湿倒影。机位沿站棚缓慢向右横移，人物只抬起视线，站位不动，站棚边缘落下几滴水。最后让路灯留在画面右侧，为下镜沿同一方向切到街口保留视线。保持脸、发型、衣服、耳钉、雨伞和场景位置。避免张伞、加路人、跳成白天、出现可读文字或换脸。
```

两条提示词演示如何分别写入同一角色和场景。图生视频需使用对应的已验首帧。

## 06 相邻镜头转场

```text
为【前镜号与末帧】和【后镜号与首帧】设计转场，切点对应【歌曲重拍、歌词或乐句】。先找两个镜头之间可连续的动作方向、物体轮廓、光线或声音，再选一种主转场方式。写清前镜何时结束、过渡从哪一处发生、后镜如何出现、预计占用几帧或多少秒。保持角色、服装和空间关系。若直接在拍点切开最顺，交代两个素材的实际裁切点。
```

## 07 MV 预告片剪辑

```text
用【音轨文件、已通过的素材清单、原始素材时间码】做一条【时长、画幅、平台】的音乐 MV 预告。目标是让观众记住【一句听感或画面】。选一段有代表性的音乐，写出可在开场辨认的声音或画面，再用少量镜头建立气氛并落到一个主要画面。结尾保留【歌名、艺人名、已确认日期或留白】。

输出剪辑单，每行给预告起止、音轨版本与源时间、画面镜号及素材源时间、对应拍点、转场和字幕停留时间。逐项核对片长、切点和可透露的内容。缺镜头时单列补拍或生成项。如果有素材、剪辑能力且本轮要求成片，按剪辑单导出并检查最终文件。
```

## 08 封面与视觉验收

```text
用【已确认的原图】为【歌名、艺人署名】做【目标比例和渠道】的封面。按【必须保留的原图区域、色彩、允许的裁切】固定底图。通过标题字号、对齐、留白与字阶建立杂志感。交付排版后检查缩小到手机缩略图时是否读得清歌名，原图裁切与色彩是否符合约束，副标题和署名是否正确。
```

## 09 审片与局部返工

```text
把【当前版本或实际导出】同【对应镜头表、定稿角色场景和选定音轨】逐项对照。检查身份、空间锚点、镜头目标、首尾连续性、切点与音乐、片长、画幅、字幕和片尾。对每个偏差给出镜号或时间码、看见或听见的问题、对应标准、应保留内容、最小修改、重新验收的方法。材料不足以判定时，列出缺少的具体文件或信息。
```
