# 封面与发布素材

只在用户要求时进入此环节。先读项目定稿的片名、主题、画幅、有效原图、署名和发布场景；标清哪些文字已确认、哪些是提案。要做封面时区分三类输入：

| 类型 | 如何处理 |
|---|---|
| 必须保留 | 原图、主体、原色、指定比例、确认署名等。按用户要求记录允许的裁切范围。 |
| 可以调整 | 标题与副标题的字阶、留白、网格、对齐、字距、文字所在的安全区。 |
| 视觉方向 | 把「杂志感 / 高级感」变成可检查的版式：例如一组主刊头、清楚的次级文字、少量装饰、对齐一致、手机缩略图仍可读。 |

**用户说「用原图，不改色」时**，把该图作为锁定底图，使用图层或排版工具加文字；不重绘、不调色、不加改变可见底色的滤镜或遮罩。可用明显的留白、文字对比或重新选字区解决阅读问题。裁切可能改变主体或构图时优先保留原构图，可加画布留白；约束无法同时满足时说明冲突。缺原图时可以先交排版方案，实际封面标为等待原图。导出后检查底图、主角及颜色、标题拼写、署名、版式层级和所需比例。

**标题和发布文案**：用已确认的作品名与署名，中英文副标题保持语义一致并适配封面长度。文案从作品中的具体动作或画面起笔，连到歌曲主题和观众会看到什么。按用户要求提供对应平台的篇幅或版本。得到的封面、文案和标题记录版本以及使用范围；制作素材不等于发布，实际发布需要用户授权。
